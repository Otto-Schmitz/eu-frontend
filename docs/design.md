# Design System

## Visual Identity
- Minimal
- Neutral
- Calm
- Trustworthy

## Color Palette
- Background: off-white / light gray
- Primary: muted blue or soft green
- Text: near-black / dark gray
- Alert (medical): red (used sparingly)

## Typography
- Sans-serif
- Large base font
- Clear hierarchy
- No decorative fonts

## Components
- Cards with subtle elevation
- Rounded corners (medium)
- Plenty of spacing
- Icons simple and universal

## Motion
- Subtle transitions
- No aggressive animations
- Motion only when it helps understanding

## Accessibility
- Large touch targets
- High contrast
- Supports font scaling
- Emergency screen optimized for visibility
