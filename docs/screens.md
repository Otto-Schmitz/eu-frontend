# Screens Definition

## Splash
- App logo
- Neutral background
- Short duration

## Onboarding
- 3 screens max
- Explain purpose, not features
- CTA: Get Started

## Auth
### Login
- Email
- Password
- Clear error messages

### Register
- Email
- Password
- Name (optional)

## Home
- Greeting
- Completion status
- Quick cards:
  - Blood type
  - Main allergy
  - Emergency contact

## Wallet
- Category cards:
  - Identity
  - Health
  - Emergency Contacts
  - Addresses
  - Documents

## Detail Screens
- Focused layout
- One section per screen
- Save button always visible
- Clear empty states

## Emergency
- High contrast
- Large text
- Read-only
- Medical ID style
- Call action for contacts

## Profile
- Account
- Security
- Export (placeholder)
- Logout
